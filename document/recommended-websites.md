# 推荐网站列表 - 适合PC端频繁切换账号的场景

本文档提供了一系列适合在PC端使用且用户需要经常切换账号登录的网站推荐，可作为Account Note插件的理想应用场景。

## 中文用户推荐网站

### 企业办公类
- **腾讯企业邮箱/阿里企业邮** - 适用场景：
  - 多部门邮箱管理（如同时管理市场部和技术部邮箱）
  - 个人邮箱与工作邮箱切换
  - 多客户邮箱管理（代理商/服务商场景）

- **钉钉/企业微信** - 适用场景：
  - 多企业组织切换（兼职/顾问场景）
  - 不同角色账号管理（管理员与普通用户）
  - 个人与企业身份切换

- **飞书/腾讯文档** - 适用场景：
  - 多团队协作空间切换
  - 个人与工作文档分离管理
  - 多项目文档管理

### 开发与技术类
- **Gitee/CODING** - 适用场景：
  - 多项目代码仓库管理
  - 个人与企业仓库切换
  - 多组织成员身份切换

- **阿里云/腾讯云** - 适用场景：
  - 多客户云资源管理（IT服务商场景）
  - 测试环境与生产环境账号分离
  - 个人与企业云账号切换

### 内容创作与管理类
- **语雀/石墨文档** - 适用场景：
  - 多知识库空间管理
  - 个人与团队文档切换
  - 多客户内容管理（内容创作者场景）

- **禅道/JIRA** - 适用场景：
  - 多项目任务管理
  - 不同角色（开发/测试/产品）账号切换
  - 多客户项目管理（外包公司场景）

### 电商与支付类
- **淘宝/京东** - 适用场景：
  - 个人与企业采购账号切换
  - 家庭多成员账号管理
  - 多店铺管理（卖家场景）

- **支付宝/微信支付** - 适用场景：
  - 个人与企业财务账号切换
  - 多商户账号管理（财务人员场景）

## 使用建议

1. **备注内容建议**
   - 记录账号用途（如"市场部邮箱"、"测试环境账号"）
   - 添加关联信息（如"对应XX客户"、"XX项目专用"）
   - 记录账号权限范围（如"管理员账号"、"只读账号"）

2. **安全提示**
   - 避免在备注中存储密码等敏感信息
   - 建议只记录辅助识别信息，而非核心验证信息
   - 定期整理不再使用的账号备注

3. **效率使用技巧**
   - 使用统一的备注格式，便于快速识别
   - 利用搜索功能快速定位特定账号
   - 对相似账号使用差异化标记，避免混淆

*注：以上推荐网站均为PC端常用且需要频繁切换账号的平台，特别适合使用Account Note插件进行账号备注管理。*
