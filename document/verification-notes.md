# Account Note - 扩展认证说明

## 基本信息

- 扩展名称：Account Note
- 版本：1.2.0
- 用途：账号备注管理工具

## 测试账号

不需要特定的测试账号。此扩展可以在任何带有登录表单的网站上测试，例如：

1. https://github.com/login
2. https://accounts.google.com
3. 任何包含登录表单的网站页面

## 功能测试步骤

### 1. 添加备注

1. 访问任意登录页面
2. 在用户名输入框中输入任意文本
3. 在登录表单中输入用户名
4. 在右侧出现的备注按钮中添加备注信息
5. 按回车键保存

### 2. 查看和编辑备注

1. 点击浏览器工具栏中的扩展图标
2. 可以看到当前网站的所有备注
3. 点击备注右侧的编辑按钮可以修改备注内容
4. 点击"管理备注"进入管理页面

### 3. 管理页面功能

1. 搜索功能：在顶部搜索框输入关键词
2. 排序功能：使用排序下拉菜单选择排序方式
3. 批量操作：
   - 点击"选择"按钮进入选择模式
   - 使用复选框选择备注
   - 点击"删除"按钮删除所选备注
4. 设置选项卡：
   - 管理已禁用网站列表
   - 查看和管理扩展设置
   - 访问关于信息

### 4. 禁用选项

1. 会话禁用：仅在当前会话中禁用扩展
2. 网站禁用：在当前网站上禁用扩展
3. 全局禁用：在所有网站上禁用扩展

## 特殊说明

1. 数据存储：

   - 所有数据仅保存在浏览器本地
   - 使用 chrome.storage.local API
   - 管理页会向已保存的网站请求 `/favicon.ico` 显示图标；请求不包含备注内容
2. 权限说明：

   - storage：用于本地数据存储
   - activeTab：支持用户在当前标签页发起的扩展操作
   - 内容脚本在 manifest 声明的 `<all_urls>` 页面匹配上运行，在本地识别账号输入框
3. 隐私保护：

   - 不会将备注内容、用户名、密码或设置上传到开发者服务器
   - 备注保存和表单识别在本地完成；站点图标及 GitHub 支持链接需要网络

## 依赖说明

- 无第三方运行时依赖；构建工具见 `package.json` 的 `devDependencies`
- 无需额外服务或API
- 备注功能不使用第三方运行时 API 或云服务；站点图标和 GitHub 支持链接需要网络

## 测试建议

1. 在多个不同的登录页面测试添加备注
2. 验证备注是否正确关联到特定网站和用户名
3. 测试批量操作和搜索功能
4. 确认数据在浏览器重启后仍然保持
5. 测试所有三种禁用选项并验证它们是否按预期工作
