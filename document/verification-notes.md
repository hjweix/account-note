# Account Notes - 扩展认证说明

## 基本信息

- 扩展名称：Account Notes
- 版本：1.0.0
- 用途：账号备注管理工具

## 测试账号

不需要特定的测试账号。此扩展可以在任何带有登录表单的网站上测试，例如：

1. https://github.com/login
2. https://accounts.google.com
3. 任何包含用户名和密码输入框的登录页面

## 功能测试步骤

### 1. 添加备注

1. 访问任意登录页面
2. 在用户名输入框中输入任意文本
3. 点击密码输入框
4. 在右侧出现的备注框中输入备注信息
5. 按回车键保存

### 2. 查看和编辑备注

1. 点击浏览器工具栏中的扩展图标
2. 可以看到当前网站的所有备注
3. 点击备注右侧的编辑按钮可以修改备注内容
4. 点击"管理备注"进入管理页面

### 3. 管理页面功能

1. 搜索功能：在顶部搜索框输入关键词
2. 排序功能：使用排序下拉菜单选择排序方式
3. 批量操作：
   - 点击"选择"按钮进入选择模式
   - 使用复选框选择备注
   - 点击"删除"按钮删除所选备注

## 特殊说明

1. 数据存储：

   - 所有数据仅保存在浏览器本地
   - 使用 chrome.storage.local API
   - 不需要任何网络连接
2. 权限说明：

   - storage：用于本地数据存储
   - activeTab：用于识别当前页面的登录表单
   - tabs：用于在管理页面显示网站信息
3. 隐私保护：

   - 不收集任何用户数据
   - 不存储任何密码信息
   - 不需要任何在线服务

## 依赖说明

- 无第三方依赖
- 无需额外服务或API
- 完全离线运行

## 测试建议

1. 在多个不同的登录页面测试添加备注
2. 验证备注是否正确关联到特定网站和用户名
3. 测试批量操作和搜索功能
4. 确认数据在浏览器重启后仍然保持
