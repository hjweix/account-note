# PassNote 隐私政策

## 数据收集
PassNote 不会收集或上传任何用户数据。所有数据（包括备注信息、用户名等）均存储在用户的浏览器本地存储中。

## 数据存储
- 所有数据仅保存在用户本地
- 使用 Chrome 浏览器的 storage.local API 进行存储
- 不会与任何远程服务器通信
- 不会在不同设备间同步数据

## 权限说明
本扩展需要以下权限：
1. `storage`: 用于在本地存储备注数据
2. `activeTab`: 用于识别当前页面的密码输入框
3. `tabs`: 用于在管理页面中显示网站信息

## 数据安全
- 所有数据均存储在浏览器的安全存储区域
- 不会收集或存储用户的密码信息
- 不会与第三方共享任何数据

## 用户控制
用户可以随时：
- 删除已保存的备注信息
- 清除所有存储的数据
- 卸载扩展并完全移除所有数据
