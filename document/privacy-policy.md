# Account Note 隐私政策

最后更新：2026-10-10

Account Note 是一款在浏览器本地管理账号备注的扩展。本文说明扩展会处理哪些信息，以及何时会发出网络请求。

## 本地保存的信息

扩展将用户创建的备注及其关联的网站域名、用户名、标签、收藏状态、手动锚定和偏好设置保存在浏览器的 `chrome.storage.local` 中。扩展不会读取或保存密码。

## 网络请求与信息共享

- Account Note 不会把备注内容、用户名、密码或设置上传到开发者服务器，也不包含云同步、广告或分析服务。
- 管理页面会请求已保存网站的 `/favicon.ico` 来显示站点图标。该请求发往对应网站；网站可能因此收到域名、IP 地址和常规请求元数据。请求不包含备注内容。
- 用户主动打开 GitHub 更新日志或支持页面时，浏览器会访问 GitHub，并适用 GitHub 自己的隐私政策。

核心的备注保存和表单识别在浏览器本地完成。站点图标及外部支持页面需要网络连接。

## 扩展权限和页面访问

- `storage`：在浏览器本地保存备注及设置。
- `activeTab`：支持用户在当前标签页中发起的扩展操作。
- manifest 将内容脚本配置为匹配 `<all_urls>`，以便在网页中本地识别账号输入框并显示对应备注。页面表单内容不会因此上传。

## 数据删除

用户可在扩展管理页面删除备注或清除扩展数据。卸载扩展也会移除其本地数据。导出的备份文件由用户自行选择保存位置和管理。

## 联系方式

如需反馈隐私问题或提交建议，请在 [Account Note GitHub 仓库](https://github.com/hjweix/account-note) 提交 Issue。
