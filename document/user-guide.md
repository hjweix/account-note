# Account Notes 用户指南

## 功能介绍

### 基本功能
- ✓ 自动识别登录表单
- ✓ 快速添加账号备注
- ✓ 集中管理所有备注
- ✓ 搜索和排序功能

### 使用方法

1. 添加备注
- 在登录页面输入用户名
- 点击密码框时会显示备注按钮
+ - 在登录页面，当密码框获得焦点时会显示备注按钮
- 点击"添加备注"输入备注信息
+ - 点击"添加备注"，输入该账号相关的备注信息
- 点击保存即可

2. 查看备注
- 再次访问该网站时
- 输入相同用户名
- 备注信息会自动显示
+ - 再次访问该网站并输入用户名时
+ - 相关的备注信息会自动显示在密码框旁边

3. 管理备注
- 点击扩展图标打开管理面板
+ - 点击扩展图标，可以查看当前网站的所有账号备注
- 可以进行编辑、删除等操作
+ - 点击"管理备注"进入管理页面，可以集中管理所有备注
+ - 支持搜索、排序、批量删除等操作

4. 数据导入导出
- 在管理页面点击"导出数据"按钮
- 选择保存位置，系统会将所有备注导出为JSON文件
- 需要恢复数据时，点击"导入数据"按钮
- 选择之前导出的JSON文件即可恢复备注信息

## 注意事项
- 备注信息仅保存在本地
+ - 我们不会存储任何密码信息
+ - 所有备注信息仅保存在本地浏览器中
- 请勿在备注中填写敏感信息
+ - 建议不要在备注中填写敏感信息

## 快捷键
- `Enter`: 保存备注
- `Esc`: 取消编辑
- 点击页面空白处：关闭备注弹窗

## 常见问题

### Q: 为什么有些密码框无法显示备注？
A: 可能是因为该页面的用户名输入框无法被正确识别。请确保先输入用户名。

### Q: 备注会自动同步到其他设备吗？
A: 不会。所有数据仅保存在当前浏览器中。

### Q: 如何备份我的备注数据？
A: 在管理页面中，点击"导出数据"按钮可以将所有备注导出为JSON文件保存到本地。需要恢复数据时，使用"导入数据"功能选择备份文件即可。

### Q: 备注信息会泄露吗？
A: 不会。所有数据仅存储在您的浏览器本地，不会上传到任何服务器。
