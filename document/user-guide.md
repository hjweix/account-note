# Account Note 用户指南

## 功能介绍

### 基本功能
- ✓ 自动识别登录表单（评分制引擎，无需配置）
- ✓ 快速添加账号备注
- ✓ 手动锚定识别不到的输入框
- ✓ 集中管理所有备注
- ✓ 搜索、排序与标签筛选
- ✓ 删除可撤销（回收站保留 7 天）
- ✓ 灵活禁用选项
- ✓ 数据备份与恢复

### 使用方法

1. 添加备注
- 在登录页面聚焦账号输入框（输入用户名更佳）
- 输入框右侧弹出备注卡，点击卡片正文即可输入
- `Enter` 保存，`Esc` 取消；点「＋标签」可加标签

2. 查看备注
- 再次访问该网站并聚焦账号框时
- 对应的备注卡会自动出现在输入框右侧（避让浏览器密码管理器）
- 备注较长时点「更多」原地展开，再点「收起」

3. 管理备注
- 点击扩展图标，查看当前网站的所有账号备注，可直接编辑、收藏
- 识别不到输入框时，用「手动指定输入框」在页面上点选一次即可
- 点击「管理备注」进入管理页面：搜索、排序、标签筛选、批量删除
- 删除的备注进回收站保留 7 天，toast 上点「撤销」立即恢复

4. 数据导入导出
- 在管理页面点击「导出数据」，全部备注与设置（标签、主题、锚定等）导出为一个 JSON 文件
- 需要恢复时点击「导入数据」选择该文件；新旧格式备份均支持

5. 禁用功能
- 悬停备注卡右上角 ⚙ 图标：选择「本次会话 / 此网站 / 所有网站」禁用
- 点 ✕ 仅收起本次弹窗
- 已禁用状态可在管理页设置中取消，或通过工具栏弹窗的「启用备注功能」一键恢复

## 注意事项
- 所有备注信息仅保存在本地浏览器中
- 备注功能完全独立于登录过程，不读取、不存储密码
- 建议不要在备注中填写敏感信息

## 快捷键
- `Enter`: 保存备注
- `Esc`: 取消编辑 / 关闭弹窗 / 退出输入框拾取模式
- `Ctrl+Enter` / `Cmd+Enter`: 管理页保存备注编辑
- 点击页面空白处：关闭备注弹窗

## 常见问题

### Q: 为什么有些登录表单无法显示备注？
A: 先确认已输入用户名（空值时不弹出）。仍不出现时，点扩展图标用「手动指定输入框」将该输入框锚定一次，之后自动生效。

### Q: 备注会自动同步到其他设备吗？
A: 不会。所有数据仅保存在当前浏览器中，跨设备请用「导出数据 / 导入数据」。

### Q: 如何备份我的备注数据？
A: 在管理页面点击「导出数据」即可将全部备注与设置导出为 JSON 文件；恢复时使用「导入数据」。备份文件带版本信封，包含标签、主题与输入框锚定记录。

### Q: 备注信息会泄露吗？
A: 不会。所有数据仅存储在您的浏览器本地，不会上传到任何服务器。

### Q: 误删了备注怎么办？
A: 删除后 7 天内，管理页 toast 上点「撤销」即可恢复；也可以从删除前的备份文件重新导入。

### Q: 如何在不需要备注时暂时禁用功能？
A: 悬停备注卡右上角 ⚙，选择「本次会话 / 此网站 / 所有网站」三种粒度之一。

### Q: 如何恢复已禁用的功能？
A: 会话级禁用在重新打开浏览器后自动失效；网站禁用可在管理页设置中取消；也可以点扩展图标，使用「启用备注功能」一键恢复当前站点。
