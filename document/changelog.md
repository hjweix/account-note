# Account Note 更新日志

## v1.0.2 (2025-02-19)
### 新增功能
- 添加备注管理功能，支持添加、编辑和展示备注
- 实现备注窗口精确定位
- 优化存储机制，添加创建时间和更新时间字段
- 支持备注数据的导入导出功能
  - 支持将备注数据导出为JSON格式文件
  - 支持导入JSON格式的备注数据
  - 实现数据冲突检测和处理机制

- 改进备注窗口样式和定位
- 优化用户交互体验
