# Account Note 更新日志

## v1.2.0 (2026-09-17)
### 新增功能
- **按网站归属备注**：备注跟着「网站」走而不是精确网址——登录子域写的备注，登录后的主站也能看到；同域下的平级子域（uat / dev / prod）默认各记各的，互不串号。管理页新增「站点范围」，可逐站切换「跟随上下级 / 仅本站」
- **评分制识别引擎**：综合关键词（含中文）、登录表单结构与输入框属性加权打分，自动锁定账号框，替代单一关键词匹配
- **手动锚定记忆**：识别不到的输入框可从工具栏弹窗手动指定一次（页面高亮拾取，支持 Esc 退出），之后永久命中；管理页可查看与移除锚定记录
- **软删除与撤销**：删除的备注进回收站保留 7 天，toast 提供一键撤销；批量删除同样可逆
- **自绘确认对话框**：删除 / 清空 / 导入覆盖等确认全部写明影响目标，替代原生 confirm
- **数据备份信封 v2**：导出文件带版本信封，标签、主题、禁用列表、锚定记录等设置随备注一并备份；兼容旧版备份导入

### 界面焕新
- 弹窗 / 工具栏 / 管理页三端统一为 Chrome 原生风格（实心表面、8px 圆角、中性灰 + 单一蓝）
- 备注弹窗重排三行式：点击正文即编辑、标签行内添加、定位实测宽高并避让浏览器密码管理器
- 管理页设置重构为「左分区导航 + 四面板」（外观 / 站点 / 标签 / 数据与关于），面板切换取代纵向滚动：站点级三张列表（备注作用域 / 已禁用网站 / 输入框锚定）合并为一张站点表，一行一站、行内展开；标签改为胶囊云
- 管理页备注列表**按站点分组**：组头为站点图标 + 域名 + 备注数（含收藏标记），同站账号聚合一处；筛选 / 排序 / 批量操作合并为单条工具栏，实时显示备注数量；卡片紧凑化，同屏可见数量约翻倍
- 管理页新增首屏骨架屏；自动明暗主题；中英双语全量覆盖（各 198 条）

### 体验优化
- 弹窗 ✕ 恢复关闭语义；悬停 ⚙ 即可展开禁用菜单（会话 / 网站 / 全局）
- 工具栏弹窗「添加备注」结构化反馈：无登录框 / 已禁用 / 连接失败分别给出准确提示与一键恢复
- 工具栏弹窗在上下级站点并存多条同名备注时标出来源子域；页面弹窗对并存记录附「另有 N 条」提示
- 输入框锚定与站点禁用改为与备注同一口径：在登录子域拾取的框 / 点的禁用，主站同样生效
- favicon 改用站点自身图标并配首字母兜底，国内网络不再破图
- 长备注「更多 / 收起」原地展开；无备注时的操作给出引导提示
- 删除类 toast 文案修正；收藏切换去噪音

### 老用户升级提示
- **数据完全兼容**：所有已有备注、标签、收藏、禁用设置更新后原样保留，无需任何迁移操作；v1.1.0 及更早版本导出的备份文件可直接导入新版
- **行为变化**：备注可见范围从「精确网址」调整为「网站作用域」——登录子域写的备注，主站登录时也会显示（平级子域仍相互隔离）；可在管理页「站点范围」逐站切换回「仅本站」
