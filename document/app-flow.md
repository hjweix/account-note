# 浏览器插件功能需求文档

## 功能描述

1. **添加备注**
   - 备注存储到浏览器本地
2. **自动展示备注**
3. **备注管理**
4. **禁用功能**
   - 支持多种禁用方式
   - 提供禁用管理界面

## 详细功能描述

### 1. 添加备注

1. 当浏览器自动填充账号时，插件应在账号字段附近显示相应的备注，当用户鼠标离开表单时备注消失。
2. 弹窗中点击添加备注，用户可以输入备注内容，然后保存或者取消。
3. 插件自动识别用户名+网站域名作为唯一Key用于存储备注。
4. 备注信息完全本地存储，不会上传服务器或者多端同步。

### 2. 自动展示备注

1. 当浏览器自动填充账号后，插件自动识别登陆表单，并通过表单中填写的用户名+当前网站域名作为Key值去匹配备注信息，如果有匹配到备注则在登陆表单右侧通过一个窗口展示备注。
2. 备注展示窗口中会有一个编辑按钮，用户点击后可以编辑当前备注，并且有保存按钮。
3. 备注展示窗口必须不能影响网站登陆表单的展示与操作。
4. 备注内容过长时默认显示前100个字符，添加"展开"按钮查看完整内容。
5. 备注窗口提供关闭按钮，点击后显示禁用选项。

### 3. 备注管理

1. 可以查询所有备注信息，展示用户名、网站域名、创建时间信息。查询界面中可以对备注信息进行删除与修改。
2. 支持导出所有备注数据为JSON文件，方便用户备份和迁移数据。
3. 支持导入JSON格式的备注数据文件，并与现有数据进行合并。

### 4. 禁用功能

1. 提供三种禁用方式：
   - 临时禁用：仅在当前会话中禁用备注功能
   - 网站禁用：在特定网站上禁用备注功能
   - 全局禁用：在所有网站上禁用备注功能
2. 设置界面中提供禁用管理功能：
   - 支持查看和管理已禁用的网站列表
   - 可以手动添加需要禁用的网站
   - 提供全局禁用开关

## 操作与交互流程

### 添加备注流程

1. 浏览器自动填充账号后，插件检测到表单并在右侧显示弹窗。
2. 用户点击弹窗，弹出备注输入框。
3. 用户输入备注内容，点击保存按钮。
4. 插件将备注信息存储到浏览器本地存储中，使用用户名+网站域名作为唯一Key。

### 自动展示备注流程

1. 浏览器自动填充账号后，插件检测到表单。
2. 插件使用表单中的用户名+当前网站域名作为Key值查找本地存储中的备注信息。
3. 如果找到匹配的备注信息，插件在表单右侧显示备注窗口。
4. 用户可以点击备注窗口中的编辑按钮修改备注内容，并点击保存按钮保存修改。
5. 用户可以点击关闭按钮，选择禁用方式。

### 备注管理流程

1. 用户点击插件图标，打开备注管理界面。
2. 插件从本地存储中读取所有备注信息，并展示用户名、网站域名和创建时间。
3. 用户可以在备注管理界面中选择删除或修改备注信息。

### 数据导入导出流程

1. **导出流程**
   - 用户点击导出按钮
   - 插件从本地存储中读取所有备注数据
   - 将数据转换为JSON格式
   - 自动下载备注数据文件（默认文件名：passnote_backup_日期.json）

2. **导入流程**
   - 用户点击导入按钮，选择备注数据文件
   - 插件读取并验证文件格式
   - 检查数据结构是否符合要求
   - 处理数据冲突（如果导入的数据与现有数据有重复的key）：
     * 提示用户选择保留现有数据还是使用新数据
     * 可选择跳过冲突项或覆盖现有数据
   - 将验证通过的数据保存到本地存储
   - 刷新备注列表显示

### 禁用功能流程

1. **临时禁用**
   - 用户点击备注窗口的关闭按钮
   - 选择"在本次会话中禁用"
   - 插件在当前会话中停止显示备注
   - 浏览器关闭后自动恢复

2. **网站禁用**
   - 方式一：通过备注窗口
     * 点击关闭按钮
     * 选择"在此网站上禁用"
     * 当前网站被添加到禁用列表
   - 方式二：通过设置界面
     * 打开设置界面
     * 在禁用网站管理中添加网站域名

3. **全局禁用**
   - 方式一：通过备注窗口
     * 点击关闭按钮
     * 选择"在所有网站上禁用
