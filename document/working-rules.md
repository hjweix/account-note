# 工作规范文档

## 会话中的工作记录要求

### 1. 进度日志记录
每次工作会话结束时，必须更新 `progress.md` 文件，记录：
- 本次实现的功能
- 遇到的错误
- 错误的解决方案

### 2. 会议总结报告
每次会话结束时，必须更新 `project-status.md` 文件，包含：
- 本次会议完成的工作内容
- 解决的技术难点
- 下次会议需要准备的内容
- 项目整体进度的追踪
- 对后续工作的建议

## 检查清单

每次开始新的工作会话时，需要：

1. [ ] 检查 progress.md 了解项目当前进度
2. [ ] 检查 project-status.md 了解整体项目状态
3. [ ] 确认本次会话的工作目标
4. [ ] 准备相应的技术方案

每次结束工作会话时，需要：

1. [ ] 更新 progress.md 记录实现细节
2. [ ] 更新 project-status.md 总结会议内容
3. [ ] 确认所有变更都已记录
4. [ ] 规划下次会话的工作内容
