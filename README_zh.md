# Account Note (账号备注助手)

一个浏览器扩展插件，帮助您为在线账号添加和管理备注。在登录页面自动显示账号备注，帮您一眼区分「这是哪个账号」，并将所有备注集中管理。

[English](./README.md)

## 功能特点

- **智能识别**：评分制识别引擎，综合关键词、表单结构与输入框属性自动锁定账号框，无需任何配置
- **手动锚定**：识别不到的输入框（多步登录、延迟渲染）可手动指定一次，之后永久命中
- **快速备注**：聚焦账号框即弹出备注卡，点击正文直接编辑，回车保存
- **按网站归属**：备注跟着「网站」走，而不是精确网址——登录域写的备注登录后主站也看得到；同域下多套环境（如 uat / dev / prod）默认各记各的，可在管理页逐站调整
- **标签分类**：行内添加标签，按标签筛选整理备注
- **收藏功能**：星标收藏重要账号，快速访问
- **搜索筛选**：按网站、用户名、标签或内容搜索；支持排序
- **放心删除**：删除进回收站保留 7 天，随时撤销；批量操作同样可逆
- **数据备份**：一键导出 / 导入 JSON 备份（含标签、主题、锚定等全部设置）
- **免打扰控制**：单次隐藏 / 站点禁用 / 全局禁用三种粒度，悬停即达
- **原生体验**：Chrome 风格原生界面，自适应明暗主题，中英双语
- **安全存储**：所有数据仅存于浏览器本地，与密码完全无关

## 安装方法

### Chrome 网上应用店

1. 访问 [Chrome 网上应用店](https://chrome.google.com/webstore)
2. 搜索 "Account Note"
3. 点击"添加到 Chrome"

### 手动安装

1. 下载或克隆此仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"并选择 `dist` 文件夹

## 使用说明

### 添加备注

1. 在登录页面聚焦账号输入框（或从工具栏弹窗点「去页面添加备注」）
2. 输入框右侧会弹出备注卡
3. 点击备注卡正文即可输入，回车保存，Esc 取消
4. 点「＋标签」可为这条账号加标签

### 查看与管理

- 再次聚焦同一账号框，备注卡自动出现
- 点工具栏图标：查看当前站点的全部备注、收藏、编辑或手动指定输入框
- 管理页面：备注按站点分组展示（同站账号聚合一处），搜索、排序、标签筛选、批量删除、实时计数
- 删除的备注进回收站保留 7 天，toast 上点「撤销」即可恢复

### 备注卡的免打扰控制

- 悬停备注卡右上角 ⚙：选择「本次会话 / 此网站 / 所有网站」禁用
- 点 ✕ 仅收起本次弹窗
- 禁用状态可随时在管理页或工具栏弹窗中恢复

## 隐私与安全

- 所有数据仅存储在浏览器本地
- 不会上传任何数据到服务器
- 备注仅与网站和用户名关联
- 不读取、不存储任何密码
