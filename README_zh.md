# Account Note (账号备注助手)

一个浏览器扩展插件，帮助您为在线账号添加和管理备注。可以在任何登录页面快速添加备注，并集中管理所有账号备注。

[English](./README.md)

## 功能特点

- **智能识别**：自动识别网页上的密码字段和账号字段
- **快速备注**：点击即可在登录页面直接添加备注
- **标签分类**：使用自定义标签整理备注，便于筛选
- **收藏功能**：将重要备注标记为收藏，快速访问
- **搜索筛选**：按网站、用户名、标签或内容搜索备注
- **安全存储**：所有数据存储在浏览器本地
- **响应式设计**：适配各种屏幕尺寸

## 安装方法

### Chrome 网上应用店

1. 访问 [Chrome 网上应用店](https://chrome.google.com/webstore)
2. 搜索 "Account Note"
3. 点击"添加到 Chrome"

### 手动安装

1. 下载或克隆此仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"并选择 `dist` 文件夹

## 使用说明

### 添加备注

1. 在登录页面上点击任意输入框
2. 输入框旁会出现备注图标
3. 点击图标添加或编辑备注
4. 按回车保存，按 Esc 取消

### 管理备注

- 点击浏览器工具栏中的扩展图标查看当前网站的备注
- 使用管理页面查看和整理所有备注
- 按网站、用户名或内容搜索
- 按标签或收藏状态筛选
- 批量选择和删除备注

## 隐私与安全

- 所有数据仅存储在浏览器本地
- 不会上传任何数据到服务器
- 备注仅与网站和用户名关联
- 不会涉及任何账号密码信息
