# 截图制作指南

## 截图要求

### 尺寸规格
- Chrome商店主图：1280x800像素
- 预览图：640x400像素

### 内容建议
1. 登录页面截图
   - 展示账号输入框获得焦点时的备注弹窗
   - 确保界面整洁，移除无关内容
   - 添加适当的阴影和边框效果

2. 管理界面截图
   - 展示备注列表和搜索功能
   - 突出显示重要操作按钮
   - 使用真实的示例数据

3. 设置页面截图
   - 展示新的卡片式布局
   - 包含所有主要设置选项
   - 确保文字清晰可读

### 视觉优化
- 使用高分辨率显示器进行截图
- 添加适当的视觉引导（如高亮重要功能）
- 保持界面风格统一
- 确保文字和图标清晰

### 文件命名
- screenshot-login.png：登录页面截图
- screenshot-management.png：管理界面截图
- screenshot-settings.png：设置页面截图

### 注意事项
1. 截图前确保使用最新版本的插件
2. 选择合适的网站进行功能演示
   中文用户推荐网站：
   - 腾讯企业邮箱/阿里企业邮：适合企业多部门邮箱账号管理
   - 钉钉/企业微信：适合企业内部多角色账号切换
   - 飞书/腾讯文档：适合团队协作场景下的多账号管理
   - Gitee/CODING：适合开发者多项目仓库账号管理
   - 语雀/石墨文档：适合内容创作者多空间切换场景
   - 禅道/JIRA：适合项目管理中的多项目切换场景
   - 阿里云/腾讯云：适合运维人员多云账号管理场景
   
   英文用户推荐网站：
   - Google Workspace/Microsoft 365：适合企业多部门邮箱管理
   - Slack/Discord：适合多工作空间和社区切换场景
   - GitHub/GitLab：适合开发者多组织仓库账号管理
   - Notion/Confluence：适合团队知识库多空间切换
   - AWS/Azure：适合云服务多账号管理场景
   - Trello/Asana：适合项目管理多团队切换场景
   - Dropbox/Box：适合文件存储多账号切换场景
3. 避免显示敏感信息
4. 保持界面语言统一（中文/英文）
